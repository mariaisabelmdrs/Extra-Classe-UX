## 📋 Sobre a Atividade

O projeto consiste em uma página principal (`index.html`) que dá acesso a questão prática, explorando diferentes conceitos de estruturação e estilização web:

- Utilização do **Bootstrap 5** em conjunto com CSS externo.
- Criação de uma tabela de marcas de carros com suas respectivas cores, modelos e classes contextuais do Bootstrap (`Primary`, `Success`, `Danger`, etc.).
- Efeito de destaque nas linhas da tabela ao passar o mouse.

## 🛠️ Tecnologias Utilizadas
- **HTML5**
- **CSS3**
- **Bootstrap 5**
